# TinyBloom Mobile v0.3.0 Beta 1

这是 TinyBloom Android 移动端的首个公开试运行版本。它与桌面端共享 C++ 业务逻辑、SQLite 数据结构和 `schemaVersion: 2` JSON 备份格式，并针对触控和窄屏重新设计了导航与长期任务页面。

> 当前为 Pre-release 测试包，适合愿意帮助测试的用户。重要数据请定期在“设置 → 数据”中导出 JSON 备份。

## 普通用户下载安装

1. 下载 `TinyBloom-Mobile-v0.3.0-beta.1-Android-arm64-Test.apk`，不要下载 Source code 源码压缩包。
2. 在手机的“下载”或文件管理器中点击 APK。
3. 如果系统拦截安装，请只为当前使用的浏览器或文件管理器临时开启“允许安装未知应用”。
4. 安装完成后可以关闭这项授权。

请只从 TinyBloom 的 GitHub 或 Gitee 官方 Release 页面下载 APK。

## 主要功能

- Today、任务、大任务、花园自习室和设置五个移动页面。
- 适合手机触控的底部导航和响应式弹窗。
- 大任务、阶段和行动步骤组成的纵向目标地图。
- 小粉花、向日葵、郁金香和玫瑰，以及 25 分钟专注计时器。
- 任务、子任务、XP、等级和花园活力。
- 简体中文（默认）与 English。
- Mint Garden 与 Midnight 主题。
- 使用 Android 系统文件选择器导入、导出 JSON 数据。

## 兼容性

- Android 9（API 28）及以上。
- ARM64（`arm64-v8a`）手机。
- 当前未上架应用商店，需要通过 APK 安装。
- 当前不包含桌面端与手机端的自动云同步；可使用 JSON 导出和导入迁移数据。

## 测试签名说明

本 APK 使用测试签名，只用于试运行。Android 可能显示“未知来源应用”或类似安全提示。未来切换到长期正式签名时，测试版可能无法直接覆盖升级；请先导出 JSON 备份，再卸载测试版并安装正式版。
