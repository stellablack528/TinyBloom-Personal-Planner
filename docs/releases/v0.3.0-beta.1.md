# TinyBloom Desktop v0.3.0 Beta 1

这是 TinyBloom Desktop 的公开测试版本，重点是把“日常小步骤”和“长期大目标”连接起来，并让花园真正成为鼓励持续行动的自习空间。

> 当前版本为 Pre-release，推荐愿意参与测试的用户使用。升级前请先在“设置 → 数据”中导出一份 JSON 备份。

## 下载方式

- **安装版**：适合大多数 Windows 用户，会创建开始菜单入口，并可选择创建桌面快捷方式。
- **便携版 ZIP**：完整解压后运行 `TinyBloom.exe`，请勿只复制单个 EXE。
- **SHA-256**：可用于验证下载文件是否完整。

## 新增：长期任务目标地图

- 新增独立的“大任务”页面。
- 为长期目标填写愿景和目标日期。
- 使用“大任务 → 阶段 → 行动步骤”的树状地图进行拆解。
- 阶段与行动步骤均可新增、改名、勾选和删除。
- 自动计算叶子步骤完成率。
- 完成所有最终步骤后，大任务自动完成并进入 XP 奖励体系。
- 长期任务与普通任务分开显示，避免日常清单变得复杂。

## 升级：花园自习室

- 花园升级为独立的花园自习室。
- 支持两个独立花位。
- 可选择小粉花、向日葵、郁金香和玫瑰。
- 花朵根据播种后获得的 XP 独立成长。
- 支持重新播种和轻量成长动画。
- 新增 25 分钟专注计时器，可开始、暂停和重置。
- 继续保留活力衰减：长期不行动时花朵会萎靡，但随时可以通过新的行动恢复。

## 任务体验修复

- 任务卡片增加直接可见的删除按钮，并保留二次确认。
- 连续勾选或删除多个任务时，列表不再自动滚回顶部。
- 重新设计筛选栏，解决多个按钮同时高亮和对齐问题。
- “进行中”现在会正确显示未来和未指定日期的未完成任务。

## 性能与稳定性

- 使用 `QThreadPool` 在后台完成 JSON 序列化和文件写入。
- 使用队列回调安全更新界面，导出期间会阻止重复操作。
- SQLite 仍固定在所属线程中，避免跨线程数据库崩溃。
- 设置中新增“兼容渲染模式”，显卡驱动不稳定时可以在重启后使用软件渲染。
- 新增旧数据库迁移、长期任务树、后台导出和增量模型测试。

## 数据兼容

- v0.2.0 的本地数据库会在启动时自动补充新字段。
- JSON 数据结构版本升级为 Schema 2。
- 导入前仍会自动创建安全备份。
- 本版本仍然是 Local-first，不需要账号、MySQL、Redis 或云服务器。

## 已知限制

- 当前只提供 Windows x64 构建。
- 长期任务地图当前支持“阶段 + 行动步骤”两层拆解。
- 专注计时器尚未保存历史专注记录。
- 跨设备同步和移动端尚未实现。
- 兼容渲染模式需要重启应用后生效。
