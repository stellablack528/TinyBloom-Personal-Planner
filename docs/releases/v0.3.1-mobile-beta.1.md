这是一次 Android 紧急兼容性更新，重点修复部分 iQOO / OriginOS 设备安装后无法启动、提示应用遇到致命错误的问题。

## 本次修复

- 改用 TinyBloom 独立且稳定的正式发布证书，不再使用 Android Debug 测试证书。
- 同时启用 APK Signature Scheme v1、v2 和 v3，提高 OriginOS 等厂商安装器的识别兼容性。
- 关闭 Android Release 的 R8 代码裁剪，完整保留 Qt Java 启动桥和运行时插件。
- 恢复完整的 Qt Quick Controls 运行样式，避免设备端动态加载组件缺失。
- 明确启用 16 KiB ELF 段对齐，并逐个检查 APK 内的 ARM64 原生库。
- 改为未压缩原生库直接映射，绕开旧包“安装时解压 `.so`”的 legacy 路径。
- 恢复 Qt 的中文系统错误文本资源，方便真实用户反馈。

## 兼容性

- Android 9（API 28）及以上。
- ARM64（`arm64-v8a`）手机。
- 已针对 Android 15/16 的 16 KiB 内存页要求进行构建检查。
- 重点兼容验证设备：iQOO Neo10 Pro+ / OriginOS 6。

## 安装说明

由于本版由测试证书切换为正式发布证书，旧测试版不能直接覆盖安装。请先卸载 `0.3.0-beta.1`，再安装本版。TinyBloom 当前数据仅保存在本机；能够打开旧版时请先导出 JSON 备份。

若仍无法启动，请提供手机“关于手机”页面、安装提示截图，以及可获取时的 Android 日志。不要只发送“安装包已失效”，日志中第一条 `FATAL EXCEPTION` 或 `dlopen failed` 最有帮助。
