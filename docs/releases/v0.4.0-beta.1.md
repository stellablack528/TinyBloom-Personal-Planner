# TinyBloom v0.4.0 Beta 1

这是 TinyBloom 第一个桌面端与移动端统一版本号的公开测试版。它把自习室从单纯的倒计时升级为可长期回顾的专注记录，并加入应用内检查更新与更新公告。

> 当前仍为 Pre-release。升级前建议在“设置 → 数据”中导出一份 JSON 备份。

## 下载

- Windows 安装程序：`TinyBloom-Desktop-v0.4.0-beta.1-Windows-x64-Setup.exe`
- Windows 便携版：`TinyBloom-Desktop-v0.4.0-beta.1-windows-x64.zip`
- Android ARM64：`TinyBloom-Mobile-v0.4.0-beta.1-Android-arm64.apk`
- 完整性校验：`TinyBloom-v0.4.0-beta.1-SHA256SUMS.txt`

## 新功能

### 每日专注记录

- 自习室开始后自动累计真实专注时长。
- 暂停、重置和未完成的专注也会保留已经投入的时间。
- 切换页面后计时继续，每 15 秒分批写入本地 SQLite。
- 显示今日专注时长和不同阶段的鼓励反馈。
- 新增专注日历，点击日期即可查看当天累计时长。
- 专注记录跟随 JSON 数据备份导入和导出。

### 应用内检查更新

- 启动后自动检查 GitHub Release，设置页也可手动检查。
- 发现新版本时展示版本号、更新公告与直接下载按钮。
- Windows 自动选择安装程序，Android 自动选择 APK。
- 支持“稍后提醒”和“忽略此版本”。
- 检查失败不会影响离线使用和本地数据。

> 出于操作系统安全限制，TinyBloom 不会静默安装更新。点击“下载更新”后会打开系统浏览器或下载工具，下载完成后仍需由用户确认安装。

## 数据与兼容性

- JSON 备份结构升级为 `schemaVersion: 3`，新增专注历史记录。
- 旧数据库会自动创建专注统计表，不会删除原有任务、目标或花园数据。
- Windows 10/11 x64。
- Android 9（API 28）及以上、ARM64（`arm64-v8a`）。
- Android 包继续使用 v0.3.1 起启用的长期发布证书，并保留 v1、v2、v3 签名与 16 KiB 对齐。

## 已知限制

- 当前更新功能负责检查、展示公告和直接下载，安装操作仍需要用户确认。
- 当前 Android 公开包为 ARM64；32 位兼容包会根据真实设备需求单独提供。
- 专注数据目前仅保存在本机，不提供账号或云同步。
